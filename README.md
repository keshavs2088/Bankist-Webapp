# Bankist App

A simple banking web app built with HTML, CSS, and JavaScript. 

## Features

- User login with username and PIN
- Display current balance
- Display transaction history
- Format dates and currency using `Intl`
- Transfer money between accounts
- Request loan
- Close account
- Sort transactions
- Auto logout timer

## Technologies Used

- HTML
- CSS
- JavaScript
  
## Login Details

Example users:

```txt
Username: js
PIN: 1111
Username: jd
PIN: 2222
````
How to Run

Open index.html in your browser.

Note:

This is a front-end practice project.
Data is stored in JavaScript only and resets when the page reloads.
